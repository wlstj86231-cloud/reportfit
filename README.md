# 레포트핏

과제 제출 전에 필요한 PDF, 이미지, 파일명, 글자수, 참고문헌, 표 변환, 텍스트 정리, ZIP 정리를 브라우저 안에서 처리하는 도구형 웹사이트입니다.

## 주요 도구

- PDF 압축, 편집, 페이지 번호, 워터마크
- 이미지 변환, 이미지 압축
- 파일명 만들기, 파일 점검, ZIP 압축
- 글자수 계산, 텍스트 정리, 표 변환
- 참고문헌 생성, 정렬, 중복 제거, 본문 인용

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

빌드 결과는 `dist/`에 생성됩니다. Cloudflare Pages에서는 빌드 명령을 `npm run build`, 출력 폴더를 `dist`로 지정하면 됩니다.
