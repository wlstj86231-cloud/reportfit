# 레포트핏

과제 제출 전에 필요한 PDF, 이미지, 파일명, 글자수, 참고문헌, 표 변환, 텍스트 정리, ZIP 정리를 브라우저 안에서 처리하는 도구형 웹사이트입니다.

## 주요 도구

- PDF 압축, 편집, 페이지 번호, 워터마크
- 이미지 변환, 이미지 압축
- 파일명 만들기, 파일 점검, ZIP 압축
- 글자수 계산, 텍스트 정리, 표 변환
- 참고문헌 생성, 정렬, 중복 제거, 본문 인용

## 사용성

- 도구 검색으로 필요한 기능을 빠르게 찾을 수 있습니다.
- 파일 선택과 드래그 앤 드롭을 모두 지원합니다.
- 텍스트/표/참고문헌 도구에는 예시 채우기 버튼이 있어 처음 방문한 사용자도 바로 흐름을 이해할 수 있습니다.
- 결과 화면에는 다음에 이어서 쓰기 좋은 도구가 바로 표시됩니다.

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

빌드 결과는 `dist/`에 생성됩니다. Cloudflare Pages에서는 빌드 명령을 `npm run build`, 출력 폴더를 `dist`로 지정하면 됩니다.
